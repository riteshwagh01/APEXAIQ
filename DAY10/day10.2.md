# What is Data?

**Data** is a collection of raw facts, figures, observations, or measurements that do not have meaning by themselves. Data serves as the input for processing and analysis.

It can exist in various forms such as:
- Numbers
- Text
- Images
- Audio
- Video
- Sensor Readings

### Examples

- 25°C
- Rahul
- 85
- 10:30 AM
- Machine Stopped

These values alone do not provide meaningful information until they are processed.

---

# What is Information?

**Information** is processed, organized, and meaningful data that helps people understand situations and make decisions.

> **Information = Data + Processing**

### Example

### Raw Data

| Student | Marks |
|----------|-------|
| Rahul | 85 |
| Priya | 92 |
| Aman | 67 |

### Information After Processing

- Highest Marks = 92
- Average Marks = 81.3
- Total Students Passed = 3

Now the data has meaning and can be used for analysis and decision-making.

---

# Difference Between Data and Information

| Data | Information |
|------|-------------|
| Raw facts and figures | Processed and meaningful data |
| Acts as input | Acts as output |
| Unorganized | Organized |
| No direct meaning | Easy to understand |
| Used for processing | Used for decision making |

# Types of Data
# Qualitative Data and Quantitative Data

## Qualitative Data (Categorical Data)

**Definition:**  
Qualitative data describes **qualities, characteristics, or categories**. It is **non-numerical** and cannot be measured using numbers.

**Examples:**
- Gender
- Blood Group
- Eye Color
- Department
- Customer Satisfaction

**Types:**
- **Nominal:** Categories with no order (e.g., Gender, Blood Group)
- **Ordinal:** Categories with an order (e.g., Excellent, Good, Average, Poor)

---

## Quantitative Data (Numerical Data)

**Definition:**  
Quantitative data represents **numbers that can be counted or measured**. Mathematical operations can be performed on this data.

**Examples:**
- Age
- Height
- Weight
- Salary
- Number of Students

**Types:**
- **Discrete:** Countable values (e.g., Number of Students, Number of Cars)
- **Continuous:** Measurable values (e.g., Height, Weight, Temperature)

---

## Difference Between Qualitative and Quantitative Data

| Qualitative Data | Quantitative Data |
|------------------|-------------------|
| Non-numerical | Numerical |
| Describes qualities | Measures quantities |
| Used for categorization | Used for measurement and analysis |
| Example: Gender | Example: Age |

### Easy Trick to Remember

- **Qualitative = Quality** → Describes characteristics.
- **Quantitative = Quantity** → Measures numbers.

# Raw Data to Information

Raw data becomes useful information after processing.

```
Raw Data
      │
      ▼
Processing
      │
      ▼
Information
```

## Step 1: Raw Data Input

Raw facts are collected.

**Example**

```
80
90
75
88
```

---

## Step 2: Processing

The collected data is:
- Sorted
- Filtered
- Calculated
- Organized
- Analyzed

Example

```
Average = 83.25
Highest = 90
```

---

## Step 3: Information Output

The processed result provides meaningful insights.

Example

```
Class Average = 83.25
Highest Score = 90
Pass Percentage = 100%
```

# Data Sources

Data is collected from two main sources.

```
                Data Sources
                     │
        ┌────────────┴────────────┐
        │                         │
 Primary Data              Secondary Data
```

---

## Primary Data Sources

Primary data is collected directly by the researcher.

### Examples

- Door-to-door surveys
- Student thesis
- Personal interviews
- Field observations
- Questionnaires

### Advantages

- Original
- Accurate
- Specific to the research

### Disadvantages

- Time-consuming
- Expensive

---

## Secondary Data Sources

Secondary data has already been collected by someone else.

### Examples

- Internet
- Books
- Newspapers
- Government Reports
- Research Papers

### Advantages

- Quick
- Low cost
- Easily available

### Disadvantages

- May be outdated
- Less specific

---

# Difference Between Primary and Secondary Data

| Primary Data | Secondary Data |
|--------------|----------------|
| Original data | Already available data |
| Collected first-hand | Collected by others |
| More accurate | May be less accurate |
| Expensive | Less expensive |
| Time-consuming | Saves time |

# Data Gathering Steps

The data collection process follows a systematic approach.

```
Define Objectives
        │
        ▼
Identify Data Sources
        │
        ▼
Design Data Collection Methods
        │
        ▼
Collect Data
        │
        ▼
Record and Organize Data
```

---

## Step 1: Define Objectives

Clearly identify the purpose of collecting data.

**Example**

```
Measure customer satisfaction.
```

---

## Step 2: Identify Data Sources

Determine where the required data will come from.

Examples:
- Surveys
- Databases
- Sensors
- Internet

---

## Step 3: Design Data Collection Methods

Select the appropriate method for collecting data.

Methods include:
- Questionnaires
- Interviews
- Online Forms
- IoT Sensors
- Direct Observation

---

## Step 4: Data Collection

Gather data from the selected sources.

Example:

```
Collect feedback from 500 customers.
```

---

## Step 5: Data Recording and Organization

Store and organize collected data properly.

Common storage methods:
- Excel
- Databases
- Cloud Storage
- Data Warehouses

Organized data is easier to clean, analyze, and visualize.

# Summary

- **Data** consists of raw facts and figures.
- **Information** is processed data that provides meaning.
- Data is transformed into information through processing.
- Data can be classified into geographical, cultural, scientific, financial, statistical, meteorological, natural, and transport categories.
- Data supports decision-making in government, healthcare, finance, agriculture, transportation, insurance, and many other sectors.
- Data can be collected from **Primary Sources** (surveys, interviews, observations) or **Secondary Sources** (internet, books, newspapers).
- The data gathering process includes:
  1. Define Objectives
  2. Identify Data Sources
  3. Design Data Collection Methods
  4. Collect Data
  5. Record and Organize Data
